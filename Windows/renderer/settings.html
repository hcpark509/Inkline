Settings

Make a comfortable place to write.

Saving & editing

Autosave writes files that already have a location. Save a new document once to choose its name and folder.

Keyboard shortcuts

Ctrl+Enter — Compile LaTeX
Ctrl+Alt+T — Insert table
Ctrl+Alt+I — Insert figure
Ctrl+1 / Ctrl+2 / Ctrl+3 — Source / Split / Preview
Ctrl+, — Settings

Workspace appearance

Every theme has light and dark variants. Source colors and the Markdown preview update together.

Markdown PDF exports use the selected theme’s light variant. HTML and LaTeX use the styling in their source.

Typography

Choose a suggested family or type the name of another installed font. Preview fonts also apply to Markdown PDF exports. Set LaTeX fonts in its preamble.

Your local font library

Import .ttf or .otf files. Inkline keeps its own copies for the source editor and Markdown preview; a system-wide installation is not required.
