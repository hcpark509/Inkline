Inkline is a native macOS editor for Markdown, LaTeX, and HTML, with syntax coloring, previews, PDF export, project folders, and a local MCP server.

This first GitHub release includes the complete source, build and test scripts, documentation, and a prebuilt app.

### New in 1.4

- Optional autosave with an adjustable delay.
- Command-Return for LaTeX compilation.
- Four color themes with light, dark, and system appearance.
- Editable Markdown, HTML, and LaTeX table generation.
- Project folders and relative figure/input references.
- Private TrueType/OpenType font imports.
- A dedicated settings window for fonts, appearance, and editor preferences.

### Download

Download `Inkline-1.4-macOS-arm64.zip`, unzip it, and move `Inkline.app` to Applications. Quit an older copy before replacing it. Preferences and imported fonts are stored outside the app bundle.

- Requires macOS 13 or later and an Apple silicon Mac.
- The app is ad hoc signed and is not notarized.
- Markdown and HTML previews/PDF exports do not need TeX. LaTeX compilation requires a separately installed pdfLaTeX or XeLaTeX engine.
- The adjacent `.sha256` file verifies the ZIP's integrity.

See the repository README for build instructions, keyboard shortcuts, settings, and Codex MCP setup. Bundled renderer notices are in `THIRD_PARTY_NOTICES.md` and `Resources/Preview/Marked-LICENSE.md`.
