Inkline 1.4.0 brings the Inkline 1.4 feature set to Windows, alongside the native Mac app in this repository.

### Included

- Markdown, HTML, and LaTeX editing with syntax colors, Undo/Redo, search, and source/split/preview layouts.
- Live Markdown and static HTML previews, compiled LaTeX PDF preview, and PDF export.
- Optional autosave and Ctrl+Enter LaTeX compilation.
- Four themes with light, dark, and system appearance.
- An editable table generator for all three document formats.
- Project folders, relative figures, and TeX inputs.
- Private TrueType/OpenType font imports and independent source/preview typefaces.
- A dedicated Settings window.
- A local stdio MCP helper with the same twelve document tools as the Mac edition.

### Downloads

- `Inkline-1.4.0-Windows-x64-Setup.exe`: current-user installer.
- `Inkline-1.4.0-Windows-x64.zip`: ZIP distribution. Extract all files together and run `Inkline.exe`.
- `SHA256SUMS.txt`: checksums for both downloads.

Requires Windows 10/11 x64. The runtime is included; Node.js is not required. These builds are unsigned. Markdown and HTML do not require TeX; LaTeX compilation requires a separately installed MiKTeX or TeX Live engine. Imported fonts and TeX engines are not bundled.

See [Windows setup, shortcuts, and MCP instructions](https://github.com/hcpark509/Inkline/blob/main/Windows/README.md). The Mac app remains available in the separate [macOS release](https://github.com/hcpark509/Inkline/releases/tag/v1.4).
