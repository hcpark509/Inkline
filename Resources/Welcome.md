# Write in Markdown

Inkline shows your source on the left and the finished page on the right. Try editing this sentence and watch the preview update.

## A few things to try

- Make a phrase **bold** or *italic*.
- Add a link to the [Markdown guide](https://commonmark.org/help/).
- Wrap a filename like `notes.md` in backticks.
- [ ] Start a new document with ⌘N.
- [x] Open the Inkline example.

> The colors help you spot headings, links, quotes, and code while you write.
